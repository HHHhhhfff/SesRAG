1. **用例准备（已完成）**：[test-cases.md](test-cases.md)覆盖84点；原65/19点设计状态保留为历史，前置均解除。104个case具有唯一ID、明确预期及追溯；312个执行字段现已按两轮真实结果填写。
2. **分类实现**：每类一个主要脚本，中文输出 case ID、过程观察、判定和证据；一个 case 失败不得污染后续 case。退出条件是脚本从新建独立子 project 运行且严格输出分类 JSON。
3. **门禁接入**：在 `manifest.json` 登记脚本、case IDs、超时和依赖，完成正/负协议自测。退出条件是重复/遗漏/额外 case、错误 run ID、缺证据、绝对/越界证据路径或实际观察为空均不能被判 `passed`。
4. **正式验收**：先按类别 Selected 调试；冻结源码/依赖和镜像后至少两轮 All。失败、blocked、not_run 和环境限制如实写报告，不以重跑通过覆盖历史失败。
