# 004分组脚本约定

脚本按观测目标分类，一个文件只处理同类边界。每组提供`run()`返回安全evidence，主入口负责部署和清理；不要自行读取开发`.env`、私密文档，或对任意project执行销毁。

固定身份为`obs-test`，其余Thread/Run/知识库/文件/Task用独立随机身份创建。幂等用例只重放本例的键；不能依赖上次运行留下的数据。Recovery需要四类链路夹具时由主入口显式准备，不靠手工先运行某命令。

断言应验证可观察业务事实和真实指标增量／日志／protobuf，而不是断言mock自身调用。测试替身注入实际Provider边界，必须检查没有外发W3C头，不降低生产SafeHTTP规则。原事务回执、generation、取消和租约的断言不能用handler正常return替代。

输出采用[report_v1](../../../contracts/observability/report_v1.json)的状态口径。异常原文、正文、密钥、URL和DSN不得出现在结果文件；错误只留固定中文判定、白名单错误码、异常类型和文件/行投影。日志先通过严格Schema和哨兵检查再归档。

阶段计时不与父阶段求和；HTTP短耗时不混入SSE；队列数量必须保留来源有效性。计数器允许进程重启归零，不能用差分拼造跨崩溃账本。内存队列丢失数量未知时填null/unknown。

脚本与A01～A16映射、主入口命令和清理限制见[测试工程README](../README.md)。新增组须更新主入口、接入计划和本表；前轮正式验收目录不属于本轮修改范围。

`test_sse.py`由All/Recovery入口在恢复分组之后调用，使用已明确部署的`recovery_worker.py`受控40秒生成夹具，验证10个连接保持30秒后断开与游标补放；不作为缺少该夹具的独立组开放。
