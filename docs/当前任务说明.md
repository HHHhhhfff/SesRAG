	      ├─ Message（用户问题、assistant 最终回答，以及历史事实）

		  ├─ deadline_at：整个任务的硬截止时间
		  ├─ operation_id：一次业务副作用操作的稳定身份，例如这一次退款
		  └─ Run（一次执行尝试）
