# PRD 实施结果记录

本目录保存某份 PRD 或需求包完成实施并完成验证后的开发结果说明，用于记录实际交付范围和开发历史，不替代 PRD 或 ADR。

每份结果文档建议按 `编号X-SesRAG-xxx-PR.md` 命名，并至少说明：对应 PRD/ADR、版本和日期、实施范围、实际变更文件、与目标的差异、验证命令及结果、未完成事项和后续建议。未运行的检查必须明确标记为“未运行”，不得写成通过。
