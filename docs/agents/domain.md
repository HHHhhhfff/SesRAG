# Domain docs

本仓库采用 single-context 布局。

## 探索相关领域前

1. 读取根目录 `CONTEXT.md`，使用其中的稳定术语。
2. 按 `AGENTS.md` 定位当前 PRD，读取相关 `docs/adr/` 决策。
3. 结合实际代码核对实现；发现差异时明确记录。

## 术语真源

本仓库由 `CONTEXT.md` 承担工程技能所称的 `GLOSSARY.md` 职责。技能提到读取或更新术语表时，路由到 `CONTEXT.md`。不另外建立重复术语表或 `GLOSSARY-MAP.md`。

术语的含义、来源、状态和变更规则遵循现有仓库约束。

## 决策与冲突

相关 ADR 位于 `docs/adr/`，继续使用现有编号和文档格式。新增配置不改变 PRD、ADR、代码和接口文档的权威关系。与现有决策冲突时，明确指出冲突及依据，不静默覆盖。
