- 日期：2026-11-13（America/New_York）；金额均为人民币。
- 范围：部署现有SesRAG以及小规模监控；CI使用GitHub提供的Runner，服务器不承担CI构建，不在本机部署大模型或MinerU。
- 状态：完成公开资料与匿名询价核对；未登录云账号、未验证个人优惠资格、未下单、未部署或压测候选服务器。
- 当前实现依据：[Compose](../../docker-compose.yml)、[依赖](../../pyproject.toml)、[v0.3部署说明](rag-v3-development.md)。本次只增加调研记录和入口导航，不实施监控功能。

## 1. 推荐结论

**没有香港／海外地域的特定需求时，优先考虑腾讯云中国内地轻量4核8GB、120GB盘、10Mbps、1500GB/月流量的630元首年活动套餐。** 折算52.5元/月，比较符合应用、PostgreSQL/pgvector和小规模Prometheus／Grafana／Loki同机运行的规划。

预算更紧时，腾讯云普通新客4核8GB、60GB盘、5Mbps的450元首年套餐也值得比较，但系统、镜像、数据库、原件和监控共同占盘，需核对扩盘能力／费用或严格控制保留期。不能先假设活动实例一定能低价扩盘或升配。

学生极省预算可选2核4GB、60GB盘的156元首年套餐，先做少量用户、少量数据及指标监控，谨慎叠加Loki。它比当前2GB实例更合适，但不能把4GB当成完整监控体系的宽裕配置。当前校园页面没有核实到4核8GB学生专属套餐。

**萤光云适合作为香港／海外节点的月付候选；按本次公开价格，它不是当前项目的最低预算选择。** 需要同地域、同盘、相同续费口径比较，不能直接以香港线路价格与腾讯云大陆促销价判断所有场景的优劣。

上述容量判断均未在候选机器实测，不承诺固定并发、延迟或日志保留量。

## 2. 服务器与监控需要多少资源

现有应用是PostgreSQL＋pgvector、Redis、API、Worker、前端五个常驻服务，迁移服务运行后退出。模型和MinerU在外部调用；没有GPU需求。当前仓库未提供Grafana／Prometheus／Loki的完整编排或业务指标接线，购机后仍需单独设计实施。

| 运行范围 | 规划起点 | 使用约束 |
| --- | --- | --- |
| 应用＋基础指标 | 2核4GB，60GB或更大SSD | 单Worker、文档处理并发1；少量时序，7～15天指标；尽量先不启用重日志查询 |
| 应用＋指标＋集中日志 | 4核8GB，约100～120GB或更大SSD | Prometheus／Grafana，Loki单体＋Alloy；先7天日志、15天指标，再依据增长调整 |
| 更多用户、长保留或重查询 | 依据CPU／RSS／磁盘IO与实际数据量扩容 | 不能只根据核数或内存承诺服务能力 |

Grafana官方的512MB最低建议仅是Grafana自身的评估起点，不含Prometheus、Loki、PostgreSQL和业务服务。监控选型应计入时序数量、抓取间隔、查询并发及日志日增量。指标标签不要直接使用无界run_id／thread_id／chunk_id制造高基数；逐任务身份优先留在受控日志中。

指标可先用Prometheus＋Grafana及必要exporter；集中日志使用Loki＋Alloy。Promtail已于2026-03-02结束生命周期，不建议新建时继续采用。磁盘为操作系统、镜像、数据库、原件／解析产物、指标和日志分别留空间，保留余量；保留天数是配置建议，不是已验证容量保证。

CI在GitHub Runner构建、推送镜像后，服务器只拉取并部署，可减少服务器构建峰值。国内实例仍需验证最终镜像仓库的可达性。同机监控与应用存在共同故障点，主机宕机时监控也可能不可用，不等于独立可用性监测或备份。

## 4. 腾讯云学生优惠的关键条件

本次依据校园页面**当前可见产品对应的mixCvm规则**。页面同时保留2017～2021等历史规则及旧实例续费元数据，不能把它们当成当前新购权益。

- 通过腾讯云官网学生认证，覆盖中国内地高校在读专科、本科、硕士、博士等；规则写明目前支持二代身份证的大陆居民，港澳台及外籍暂不支持该验证。不能凭旧网帖认定仅年龄或edu邮箱就能享受优惠。
- “首单特惠”要求该产品无订单记录或累计订单金额为0；按同一实名认证主体限制购买，不能靠新建小号重复取得资格。是否合格最终以登录校验为准。
- 校园服务器限购；当前页面三选一为2核2GB轻量、2核4GB轻量、2核4GB CVM。学生CVM当前匿名通用询价接口返回不支持，本次未核实其成交价。
- **首单特惠不参加同价续费，2023年后活动服务器不参加同价续费。** 历史用户若仍有优惠续费资格，必须登录查看自己的入口；不能把156元写成永久年费。
- 校园首单及所比较的普通活动均规定优惠不叠加，不默认能再用代金券／学生券继续抵扣。
- 购买、退款、升配可能影响优惠资格。不要先买低配再假设无损升级仍保留学生价；购买前核对具体实例的升配、扩盘与续费规则。

实际购买建议：先学生认证，再同时打开校园156档和普通新客450／630档，以相同使用时长比较。学生身份不妨碍比较普通活动，但匿名报价不证明同一个账号仍有各档购买资格。当前已买阿里云实例不等于已消耗腾讯云同产品首单资格。

校园附带的BI、云开发或MySQL产品不等于本项目必需资源；当前向量存储是PostgreSQL＋pgvector，不能直接用MySQL赠品替换。

## 6. 萤光云的产品与性价比

已确认用户所指品牌官网为[萤光云ygcloud.com](https://www.ygcloud.com/)，并观察到lightnode.cn跳转到它。官网[服务条款](https://www.ygcloud.com/zh-cn/termsService)和[法律声明](https://www.ygcloud.com/zh-cn/legalDeclaration)声明主体为“福州市棠云万联科技有限公司”；本次未独立完成工商／备案核验，不把页脚资质当作已独立认证。

影响性价比的关键事实：

1. **学生政策：** 未查到可核实的专属学生认证、套餐、申领与续费规则；官网面向学生的通用选型文章不能作为它提供学生优惠的证据。
2. **CPU／带宽：** 页面“独享IPv4”不等于独占CPU。CPU持续占用／物理核心保障未确认；官方[知识页](https://www.ygcloud.com/knowledge/1395/)说海外VPS共享带宽，香港落地页又宣称独享带宽，口径存在冲突。100Mbps不能据此认定为持续独享保障。
3. **退款：** 首单5天退款不等于免费试用；服务条款写退款先到平台余额，提现需联系客服，可能收3%服务费、3～5工作日。下单前确认自己所选订单的适用范围。
4. **备份：** [正式帮助](https://www.ygcloud.com/zh-cn/panHelp)写每账户免费1个快照，每硬盘新快照覆盖旧快照；不等于异地多版本数据库备份。备份恢复需另做。
5. **续费／SLA：** 官网写续费与当时页面价格相关，年付不能理解为永久锁价；本次未找到含完整月度口径、排除项、赔付比例及期限的公开SLA，不把营销可用性数字当作已验证承诺。

因此：若主要使用者在内地、主要追求学生预算，优先腾讯云大陆轻量；若明确需要香港／海外地域或不同流量结构，可将萤光云4核8GB月付加入候选，先核实100GB盘总价和真实用户网络，再决定长期付费。大陆与香港的网站备案适用条件不同，地域是选型条件，不能只比首年价格。

## 7. 下单前的核对顺序

1. 确定地区、账户学生／新客资格，以及首年和后续两年的总预算；不在本次调研中预先购买。
2. 选择Linux x86_64系统，优先Ubuntu24.04／22.04 LTS，不买GPU；确认套餐支持自定义Docker部署。
3. 记录同一规格的首购总额、续费报价、盘和带宽／流量、扩容条件、快照及退款条款，避免只保存首页折合月价。
4. 部署前测试镜像仓库、模型与MinerU可达性；CI用GitHub Runner不代表应用服务器无需访问镜像或外部API。
5. 业务与监控分别持久化，限制日志及指标保留；数据库备份放到独立存储并验证恢复。Grafana／Prometheus／Loki端口不直接作为无认证公网入口。
6. 不把云监控产品与自建开源监控混淆：腾讯云有[托管Grafana](https://cloud.tencent.com/product/tcmg)和[Prometheus](https://cloud.tencent.com/product/tmp)，但并非购买轻量主机自动包含、也不等于全部免费。学生预算先比较自建的主机／磁盘成本。
